# Acceptance test plan

Each line is a requirement of the subject.

- **Implemented**: date of the commits that added the feature (from `git log`).
- **Status**: ✅ checked, ❌ failed, ⬜ not tested yet, with the date of the test.
- "Without window" means the test ran the same code as the game
  (`Parser` → `MazeLoader` → `Game`) on test files, without opening the window.
- "Real game without window" means the whole game (`App` and its screens) ran with
  the SDL `dummy` video driver: same code, but nothing is shown on screen.
