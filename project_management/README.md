# Project management

This folder holds the evidence of how we managed the Pac-Man project
(elbarry: graphics, larchimb: logic).

## Method

We used a **Kanban board on Trello**, split into 10 phases that follow the order
of the subject:

| Phase | Planned dates |
|---|---|
| 0. Framing | 9 → 11 Oct |
| 1. Project base | 13 → 14 Oct |
| 2. Configuration | 15 → 17 Oct |
| 3. Maze and levels | 18 → 21 Oct |
| 4. Gameplay | 22 → 28 Oct |
| 5. Display and interface | 15 → 24 Oct |
| 6. Highscores | 26 → 28 Oct |
| 7. Packaging and deployment | 24 Oct → 3 Nov |
| 8. Quality and tests | 29 Oct → 4 Nov |
| 9. Documentation and submission | 5 → 7 Nov |

Each card has a checklist of sub-tasks and a due date. Each card has a color label
that shows who owns it: **yellow** = elbarry (graphics), **blue** = larchimb (logic),
**green** = shared.
